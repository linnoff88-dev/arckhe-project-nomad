Em resumo

E se a internet cair, ou você estiver onde ela não chega? O Project NOMAD é um servidor de conhecimento e educação que roda no seu próprio computador e funciona sem internet. Você instala num Linux (Debian ou Ubuntu) e abre pelo navegador: Wikipédia e livros offline, cursos da Khan Academy, mapas, um chat com IA local, notas e ferramentas de dados. Precisa de internet só para instalar e para baixar o conteúdo que quiser guardar. É um projeto aberto da Crosstalk Solutions (licença Apache 2.0).

O que faz

Uma biblioteca, uma escola e um mapa no seu hardware

O NOMAD é um painel (o “Command Center”) que instala e cuida de várias ferramentas abertas por você, tudo acessado pelo navegador.

📚 Biblioteca offline

Wikipédia, referências médicas, guias e livros, com o Kiwix.

🎓 Cursos

Cursos da Khan Academy com acompanhamento de progresso e vários usuários, com o Kolibri.

🗺️ Mapas

Mapas regionais para baixar e consultar sem conexão, com o ProtoMaps.

🤖 IA local

Chat com IA rodando no seu equipamento (Ollama), com envio de documentos e busca por significado (Qdrant).

📝 Notas e ferramentas

Anotações em markdown (FlatNotes) e ferramentas de dados como criptografia e codificação (CyberChef).

🧰 Catálogo de apps

A “Supply Depot”: um catálogo de apps em um clique e a opção de rodar seus próprios containers Docker.

Este guia é uma adaptação em português do projeto Project NOMAD, da Crosstalk Solutions (licença Apache 2.0). Site oficial: projectnomad.us. O código e as marcas pertencem aos autores; este fork em português serve só para estudo e divulgação.

Como funciona

Como funciona

O NOMAD é uma interface de gerenciamento e uma API que organizam, via Docker, um conjunto de ferramentas e conteúdos. Ele cuida da instalação, da configuração e das atualizações.

Instalar (1 comando)→Abrir no navegador→Assistente de configuração→Baixar conteúdo→Usar offline
O que você precisa

O que você precisa

O NOMAD em si é leve; o que você escolhe instalar define o tamanho. A IA é o que mais pesa.

Mínimo (só o painel)

Processador de 2 GHz com 2 núcleos, 4 GB de RAM (a pilha toda sem IA roda em menos de 1 GB) e pelo menos 5 GB livres (10 GB para ficar confortável). Sistema Debian ou Ubuntu (recomendado: Ubuntu 26.04 LTS; também 24.04 LTS e Debian 12).

Ideal (com IA)

Ryzen 7 ou Core i7, 32 GB de RAM, placa de vídeo NVIDIA RTX 3060 ou equivalente e 250 GB livres, de preferência em SSD. Só o assistente de IA leva a instalação a cerca de 25 GB.

Acesso e rede

Permissão de administrador (sudo) para instalar e internet estável durante a instalação. No Windows, o caminho é pelo WSL2 (um Linux dentro do Windows), mantido pela comunidade: guia de instalação no WSL2. Quanto espaço cada conteúdo ocupa está no FAQ oficial.

Passo a passo

Passo a passo

Os comandos abaixo vêm do README oficial do projeto.

1

Instale (Debian ou Ubuntu)

Abra um terminal no Linux e cole o bloco abaixo (ele baixa e roda o instalador; precisa de sudo). Passo a passo com Ubuntu: guia de instalação.

sudo apt-get update && \
sudo apt-get install -y curl && \
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh \
  -o install_nomad.sh && \
sudo bash install_nomad.sh
2

Abra no navegador

Terminada a instalação, entre pelo próprio computador (localhost) ou, de outro aparelho da rede, pelo endereço IP do computador onde instalou.

http://localhost:8080          # ou http://IP_DO_APARELHO:8080
3

Siga o assistente

Na primeira vez, um assistente guia a configuração e sugere coleções de conteúdo prontas. Escolha as coleções que quer baixar (Wikipédia, cursos, mapas). A IA é um app à parte, que você adiciona depois.

4

Rode a IA em outra máquina (opcional)

Por padrão o instalador põe o Ollama no mesmo aparelho. Para usar outro, informe o endereço dele nas configurações do assistente de IA (a tela de IA do NOMAD, não o assistente de configuração). No Ollama desse outro aparelho, defina esta variável de ambiente ao iniciá-lo (a configuração desse outro servidor fica por sua conta):

OLLAMA_HOST=0.0.0.0
5

Cuide do dia a dia

Depois de instalado, há scripts de manutenção na pasta do projeto.

sudo bash /opt/project-nomad/start_nomad.sh    # inicia os containers
sudo bash /opt/project-nomad/stop_nomad.sh     # para os containers
sudo bash /opt/project-nomad/update_nomad.sh   # atualiza o Command Center
Privacidade e segurança

Privacidade e segurança

O que o projeto diz sobre isso:

Internet

Só é necessária na instalação e quando você mesmo baixar conteúdo novo.

Sem login

O NOMAD não tem autenticação: foi feito para ser aberto. Se for ligar o aparelho numa rede local, controle o acesso pela rede e não o exponha direto à internet.
